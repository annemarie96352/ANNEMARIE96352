# ANNEMARIE96352 — Premium Vacation Packages

A responsive, multi-page, English-language travel website concept for GitHub Pages.

## Quick start

Open `index.html` in a browser, or upload all files to a public GitHub repository and enable **Settings → Pages → Deploy from branch → main / root**. Keep the `assets/` folder intact.

## Pages

- `index.html` — editorial landing page
- `destinations.html` — searchable, filterable, sortable sample travel catalog
- `packages.html` — vacation styles
- `cruises.html` — cruise inspiration
- `about.html` — brand story
- `journal.html` — editorial travel ideas
- `contact.html` — demo-only inquiry form
- `faq.html`, `privacy.html`, `terms.html` — information pages

## Brand

- Sky blue: `#50B8E7`
- Deep blue: `#153D61`
- Sand: `#E8D6B5`
- Slogan: **Discover the Extraordinary.**

## Important

**This is a demonstration website, not a live travel agency booking service.** All travel packages, sample prices and durations are illustrative. No bookings, payments, inventory or inquiry submissions are implemented. Before commercial launch, integrate verified travel providers, secure forms, applicable legal policies, and real customer support.

Images and fonts are loaded from external sources and require an internet connection. Check third-party asset licensing before commercial deployment.
